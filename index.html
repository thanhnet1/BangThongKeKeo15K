Hàm lưu dữ liệu hiện tại vào LocalStorage function saveDataToLocalStorage() { // Chuyển mảng matches thành chuỗi JSON và lưu vào LocalStorage localStorage.setItem(STORAGE_KEY, JSON.stringify(matches)); } // 4.
